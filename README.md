# BioTact: la Biología también se toca

Lightning talk de cinco minutos para la a11yConf de Zaragoza, 28 de noviembre de 2026.
Autor: Jose María Ortiz Silva.

Usa el mismo sistema de diapositivas que la [presentación del TFM](https://github.com/jmortizsilva/presentacion_tfm): las notas habladas van en los elementos `<step>` y `<x>`, y se anuncian por el lector de pantalla al avanzar.

## Cómo verla

Abre `index.html` en Chrome, Edge o Firefox, directamente en el navegador.

## Teclado

| Tecla | Acción |
|-------|--------|
| Espacio · → · AvPág | Avanzar un paso |
| ← · RePág | Retroceder un paso |
| Mayús + → · Mayús + AvPág | Diapositiva siguiente |
| Mayús + ← · Mayús + RePág | Diapositiva anterior |
| Inicio · Fin | Primera / última diapositiva |
| ↓ · . | Repetir el último anuncio |
| ↑ | Anunciar la hora |
| F | Pantalla completa |

## Fuentes

El contenido sale de la carpeta de trabajo del proyecto BioTact: el artículo de divulgación «BioTact: tocar, explorar y comprender la biología», el listado de láminas publicadas, las características de las pruebas del curso 2026-2027, las incidencias de los modelos 3D, las sugerencias a las láminas y el acta de la reunión mensual del 5 de noviembre de 2026.
